# 🎲 Would You Rather?

Интерактивная браузерная игра в формате **Would You Rather?** — выбирай между двумя вариантами, проходи вопросы разных жанров и в конце получай игровой профиль на основе своих решений.

## ✨ Возможности

- 5 категорий вопросов:
  - 😂 Funny
  - 💕 Relationships
  - 🪄 Impossible
  - 🥲 Sad
  - 🌱 Life Like
- 100 вопросов — по 20 на каждую категорию
- Можно выбрать одну, несколько или все темы
- Случайное расположение вариантов на красной и синей стороне
- Поддержка управления клавиатурой
- История последних ответов
- Статистика красных и синих выборов
- Прогресс прохождения
- Итоги по каждой категории
- Игровой профиль на основе смысла выбранных ответов
- Адаптивный интерфейс
- POP / comic-inspired UI
- Анимации, hover-эффекты и визуальные эффекты при выборе

---

## 🧠 Игровой профиль

Игра анализирует не просто количество красных и синих ответов.

Каждый вариант относится к определённому типу выбора. Например:

**Relationships**
- близость
- независимость
- честность
- гармония
- стабильность

**Life Like**
- свобода
- стабильность
- амбиции
- дисциплина
- баланс

**Impossible**
- свобода
- знания
- сила
- приключения
- стабильность

После игры определяется наиболее часто встречающийся тип ответа в каждой категории и формируется короткий игровой вывод.

> Результаты предназначены только для развлечения и не являются психологической диагностикой.

## 🎮 Управление

### Мышь

Просто нажми на один из двух вариантов.

### Клавиатура

| Клавиша | Действие |
|---|---|
| `←` / `A` | выбрать красный вариант |
| `→` / `D` | выбрать синий вариант |
| `H` | открыть историю |
| `Esc` | закрыть дополнительное окно |
| `Enter` | начать игру из главного меню |

Также поддерживается русская раскладка:

- `Ф` — красный вариант
- `В` — синий вариант
- `Р` — история
